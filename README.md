HOT TO USE IT:

First, download the code and open the proyect folder with an code editor which terminal must be included with it (like vs code).

If you do not want to create a pdf report, just do the analisys by tipping in the terminal of your code editor: php -S localhost:8000 and go to http://localhost:8000 (it may appear in the terminal, just click it). If dont, o to your browser and type http://localhost:8000
